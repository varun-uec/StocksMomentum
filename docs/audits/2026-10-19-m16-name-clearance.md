## Assessment
- No conflicting product or mark showed up. The "wick" prefix is common among trading tools (WickedDesk, WickScan), because a candle's wick is a charting term. That weakens distinctiveness, but no search result conflicts directly.
- A free `.io`, `.app` or `.dev` domain is enough for an open-source project. The `.com` would need a purchase.

## Still needed before the name is final (owner)
1. A formal search of the Indian Trade Marks Registry (IP India) and USPTO, in Class 9 (software), Class 42 (software services) and Class 36 (financial information).
2. Choose and register a domain.
3. Until then the name stays provisional (ADR-012).
