# Keyboard Shortcuts — Chart Workspace

The chart workspace (`/chart`) answers these keys. Press `?` there to see the same list. The source is `web/src/lib/shortcuts.ts`; keep this page in step with it.

| Keys | Action |
|---|---|
| Type a letter, / or Ctrl/⌘+K | Search for a symbol |
| ← / → | Pan the chart (chart focused) |
| Ctrl/⌘+↑ / ↓, + / - | Zoom in or out (chart focused) |
| Alt+R | Reset the view to the whole range (chart focused) |
| Alt+T | Trendline tool |
| Alt+H | Horizontal ray tool |
| Alt+Shift+R | Rectangle tool |
| Alt+F | Fib retracement tool |
| Alt+V | Vertical line tool |
| Click, drag, Delete | Select, move or delete a drawing |
| ← → ↑ ↓ (drawing selected) | Move the drawing a bar sideways, or a little up or down |
| Right-click, ContextMenu key, Shift+F10 | The drawing's menu (colour, width, text, delete), or the chart's (reset, indicators, scale, alert at a price) |
| Ctrl/⌘+Z | Undo a drawing edit made in this window |
| Ctrl/⌘+Shift+Z, Ctrl+Y | Redo |
| Esc | Cancel the tool or the selection |
| Alt+I | Open the indicator list |
| Alt+W | Add the symbol to the watchlist, or remove it |
| ? | Show these shortcuts |

Notes:
- "Chart focused" keys work after a click on the chart or a Tab to it.
- Alt shortcuts read the physical key, so they work on any keyboard layout and with Option on macOS.
- `/` always opens symbol search (design record D9).
