# Wickstreet 2.0 vs Tickertape — Live Mutual Fund Assessment

**Independent live review · 24 October 2026 · Tickertape's currently accessible mutual-fund workflows only**

> **Historical baseline.** This report records the 24 October live state. The [25 October independent benchmark](LIVE_ASSESSMENT_2026-10-25.md) supersedes it for current visual, benchmark, first-screen facts, and workflow observations. Keep this file for its prior-day Tickertape profile/screener/portfolio evidence only; do not treat its overall verdict as the 25 October verdict.

## Verdict

**Partially — Wickstreet is better in specific historical analytics and replayable research, but Tickertape is currently the better overall mutual-fund research product for an investor who needs a current fund dossier and portfolio context.** This is the closest of the permitted verdicts. The evidence does not support an overall Wickstreet win.

This is based on use of both running applications, not feature counts. Wickstreet's longitudinal NAV analysis, historical drawdown/recovery views, comparison and simulations are substantive advantages for an advanced researcher. Tickertape more readily answers the immediate questions “what does this fund cost, hold, and compare against?” and has a demonstrated authenticated portfolio-analysis workflow. Wickstreet's comparable whole-portfolio outcome was not demonstrated.

Tickertape also showed a trust defect: on the live PPFAS profile, its Scorecard listed 1Y return as **−5.69%**, while the peer table and FAQ listed **−6.68%** (the FAQ dated its result 23 October 2026). The page did not explain the difference. This prevents treating its headline figures as uniformly reliable; it does not erase its broader current-facts advantage.

## How the review was run

- An independent reviewer exercised Wickstreet at `http://localhost:8000` with current local MF data through 16 browser journeys: Discover, collection → screen → fund → Back, Return 1Y, fund facts/risk, benchmark and holdings, Compare, SIP/SWP, Studio and phone layouts. Workspace routes were mocked in memory; no personal records were changed.
- A separate reviewer exercised the live Tickertape screener, PPFAS Direct Growth public profile and an authenticated portfolio route on 24 October. No private portfolio values or holdings are reproduced. The portfolio observation proves that the workflow existed in that signed-in account; it does not prove free-tier access or public availability.
- The same representative fund was PPFAS Direct Growth. Tickertape's public page showed NAV ₹88.97 as of 23 October, TER 0.69% (base 0.53%), AUM ₹1,45,070.50 Cr, NIFTY 500 TRI, dated holdings, sector/asset allocation, manager and peer information. Values are as observed on that date, not durable claims.
- Click counts below are observed interactions. Only the Wickstreet screener has a browser-measured API response: Return 1Y arrived in about 0.6–0.8 seconds on the local environment. Network, viewport and instrumentation were not controlled across products, so elapsed-time or mobile-speed superiority is **not established**.
- Tickertape's paid markers were visible, but the public screener's 1Y absolute-return range and 3Y rolling-return control worked in this session without a gate. Do not generalize the earlier claim that all rolling-return filters are Pro-gated. Some subscription features and current unauthenticated portfolio behavior remain unverified.

## Implementation started from this baseline

**Fixed the highest-value low-effort friction that was verified in the live screener.** Basic numeric thresholds now use inline minimum/maximum inputs. They update the deterministic screen through the existing 300 ms query debounce, add the metric column automatically where space allows, preserve the current filter and advanced expression model, and do not restrict results merely by showing a metric. Enum/date/boolean and complex operators remain in the advanced condition editor.

Browser evidence against real local data after the fix:

- Show Return 1Y: **1 click**, 46 results unchanged, real column visible in **844 ms** in the final local run; the independent reviewer measured **569 ms** to visible column.
- Set Return 1Y minimum to −10%: **one Filter click plus one value entry**, no modal; real result set narrowed from **46 to 37**. The API received `ret_1y between [-0.1, null]` in stored return units.
- The final 6-test Basic screener suite passed, including phone metric selection, phone inline thresholding and advanced editor checks. Build and lint passed. On phone, reopening Filters and entering the same range returned 37 funds.
- In a separate preview, the independent reviewer typed `-10` key by key and confirmed the negative value was preserved; they also changed a preset while the range remained open and verified the input clears with the removed condition. The reviewer reproduced the 46 → 37 task and expected API payload, with no extra dialog.

This is an interaction-cost improvement, **not** proof that Wickstreet's screener now beats Tickertape overall. Tickertape still has the more familiar slider control; measure both with the same threshold task before claiming a win.
